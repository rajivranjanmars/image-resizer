# Image resizer

An interactive Python utility that resizes a PNG image to dimensions entered at the terminal using Pillow.

## Usage

Install Pillow with `python -m pip install Pillow`. From the parent directory, place an input at `image-resizer/qr.png` and run `python image-resizer/main.py`; the result is written to `image-resizer/qr_resized.png`.
